# Лабораторная работа №4

## Куча (пирамида) и очередь с приоритетом

В лабораторной работе рассматриваются реализация минимальной и максимальной кучи, пирамидальная сортировка, использование очереди с приоритетом и жадные алгоритмы.

Решения выполнены на **Python** и **C++**. Всего в папке представлены **7 задач** (задача №4 имеет два варианта решения).

---

### Задача 1. Хипуй! (№755)

**Условие.** Реализовать максимальную кучу для хранения целых чисел. Поддержать команды добавления элемента (`Insert`) и извлечения максимального элемента (`Extract`). Для каждого извлечения вывести полученное число.

**Алгоритм.** Самостоятельная реализация макс-кучи на массиве. При вставке элемент просеивается вверх, при извлечении максимума — вниз.

**Сложность:** `O(log N)` на добавление и извлечение; `O(N)` памяти.

### Задача 2. Пирамидальная сортировка (№754)

**Условие.** Отсортировать массив целых чисел **по неубыванию**, используя пирамидальную сортировку.

**Алгоритм.** Из массива строится макс-куча. На каждом шаге максимум перемещается в конец рабочей части массива, затем размер кучи уменьшается и выполняется просеивание вниз.

**Сложность:** `O(N log N)` по времени, `O(1)` дополнительной памяти для самой сортировки.

**[Решение — Python](./work%202%20%D0%BF%D0%B8%D1%80%D0%B0%D0%BC%D0%B8%D0%B4%D0%B0%D0%BB%D1%8C%D0%BD%D0%B0%D1%8F%20%D1%81%D0%BE%D1%80%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B0.py)**

### Задача 3. Пирамида (минимум) (№3493)

**Алгоритм.** Самостоятельная реализация мин-кучи в C++ с просеиванием вверх при добавлении и просеиванием вниз при извлечении. Очистка осуществляется сбросом логического размера.

**Сложность:** `O(log N)` на добавление и извлечение, `O(1)` на очистку логического размера.

### Задача 5. Коммерческий калькулятор (№746)

**Условие.** Даны `N` натуральных чисел. За каждое сложение калькулятор взимает 5% от полученной суммы. Найти минимальную суммарную стоимость вычисления суммы всех чисел и вывести её с двумя знаками после десятичной точки.

**Алгоритм.** Жадный алгоритм: на каждом шаге извлекаются два наименьших числа из мин-кучи, складываются, а их сумма возвращается в кучу. Стоимости промежуточных сложений суммируются.

**Сложность:** `O(N log N)` по времени, `O(N)` по памяти.

**[Решение — Python](./work%205%20%D0%BA%D0%BE%D0%BC%D0%BC%D0%B5%D1%80%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B9%20%D0%BA%D0%B0%D0%BB%D1%8C%D0%BA%D1%83%D0%BB%D1%8F%D1%82%D0%BE%D1%80.py)**

### Задача 6. Таможня (№1755)

**Условие.** Для каждого груза известны время прибытия и длительность обработки. Каждый груз должен начать обработку без ожидания. Определить минимальное количество аппаратов, необходимых для выполнения этого условия.

**Алгоритм.** Грузы сортируются по времени прибытия. Мин-куча хранит времена освобождения аппаратов. При поступлении нового груза используется уже освободившийся аппарат, если он есть; иначе добавляется новый.

**Сложность:** `O(N log N)` по времени, `O(N)` по памяти.

**[Решение — Python](./work%206%20%D1%82%D0%B0%D0%BC%D0%BE%D0%B6%D0%BD%D1%8F.py)**

### Задача 7. Вычислительная ихтиология (№3407)

**Условие.** В нескольких аквариумах по заданным правилам рождаются рыбки. Сотрудник должен присутствовать у соответствующего аквариума в момент каждого рождения и тратит одну секунду на переход между соседними аквариумами. Найти время первого рождения, которое он не сможет зарегистрировать.

**Алгоритм.** Моделирование событий с помощью мин-кучи: для каждого аквариума хранится ближайшее время рождения. События обрабатываются в хронологическом порядке; проверяется возможность перемещения к нужному аквариуму, после чего рассчитывается следующее рождение.

**Сложность:** `O((N + M) log N)` по времени, где `M` — количество обработанных событий; `O(N)` по памяти.

**[Решение — Python](./work%207%20%D0%B0%D0%BA%D0%B2%D0%B0%D1%80%D0%B8%D1%83%D0%BC%D1%8B.py)**
