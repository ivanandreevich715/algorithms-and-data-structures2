# Лабораторная работа №5

## Двоичные деревья поиска

В лабораторной работе реализованы основные операции над **бинарным деревом поиска (BST)**: вставка, удаление, поиск, обходы, определение высоты, проверка сбалансированности и работа с повторяющимися значениями. Последняя задача посвящена поиску следующего элемента множества.

**Язык программирования:** Python.  
**Всего:** 11 задач, 12 файлов с решениями (для задачи №11 — два варианта).

> Пусть `N` — количество входных значений, `U` — число уникальных элементов, `h` — высота дерева. Обычное BST не балансируется автоматически: при неудачном порядке добавления высота может достигать `U`.

---
### Задача 1. Бинарное дерево (вставка, поиск, удаление) (№3557)

**Условие.** Обработать команды `ADD`, `DELETE`, `SEARCH` и `PRINTTREE` над двоичным деревом поиска. При удалении вершины с двумя потомками использовать максимальный элемент левого поддерева.

**Алгоритм.** Бинарное дерево поиска с уникальными ключами. Вставка, поиск и удаление выполняются по сравнению значений; для `PRINTTREE` применяется симметричный обход с точками по глубине.

**Сложность.** `ADD`, `DELETE`, `SEARCH` — `O(h)`; обход — `O(U)` посещений вершин (вывод точек требует дополнительного времени).

### Задача 9. Сбалансированность (№764)

**Условие.** Проверить, что для каждой вершины BST высоты левого и правого поддеревьев отличаются не более чем на единицу. Вывести `YES` или `NO`.

**Алгоритм.** После обычного построения BST вычислить высоты поддеревьев снизу вверх и проверить условие `abs(left_height - right_height) <= 1` в каждой вершине.

**Сложность.** Проверка готового дерева — `O(U)` по времени; построение в худшем случае — `O(N²)`.

### Задача 11. Следующий (№2782)

**Условие.** Поддерживать операции `+ i` (добавление числа в множество) и `? i` (поиск минимального числа, не меньшего `i`, либо `-1`). Если `+ i` идёт сразу после запроса `?` с ответом `y`, добавляется `(i + y) mod 10⁹`.

**Алгоритм.** В обычном BST при поиске `next(i)` запоминать подходящего кандидата и продолжать движение влево; если текущий узел меньше `i`, идти вправо. Дополнительно приведён расширенный вариант с балансировкой.

**Сложность.** Обычное BST — `O(h)` на операцию, в худшем случае `O(U)`; расширенный вариант с декартовым деревом — ожидаемое `O(log U)` на операцию.
