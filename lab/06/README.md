**Задача №111540**

Найти все компоненты связности неориентированного графа и вывести их состав.

**Идея решения:**

- Использование итеративного DFS через стек.
- Повторный запуск обхода из каждой непосещённой вершины.

### 6. Есть ли цикл?

**Задача №98**

Определить, содержит ли ориентированный граф хотя бы один цикл.

**Идея решения:**
- Использование DFS с раскраской вершин в три цвета.
- Белый — вершина не посещена.
- Серый — вершина находится в текущем пути обхода.
- Чёрный — обработка вершины завершена.
- Обнаружение ребра в серую вершину означает наличие цикла.

**Алгоритм:** DFS + трёхцветная раскраска.

**Сложность:** O(N²).

[Перейти к решению](<work 6 есть ли цикл.py>)

### 7. Дерево?

**Задача №2868**

Определить, является ли заданный неориентированный граф деревом.

**Идея решения:**
- Проверка условия M = N − 1.
- Проверка связности графа с помощью DFS.
- Если все вершины посещены и количество рёбер равно N − 1, граф является деревом.

**Алгоритм:** DFS + проверка количества рёбер.

**Сложность:** O(N + M).

[Перейти к решению](<work 7 дерево.py>)

### 8. Путь

**Алгоритм:** Breadth First Search (BFS).

**Сложность:** O(N²).

- Хранение восьми возможных перемещений коня.

### 10. Топологическая сортировка

**Задача №114091**

**Алгоритм:** проверка топологического порядка.

**Сложность:** O(N + M).

## Основные алгоритмы и структуры данных

| Алгоритм / структура | Назначение |
|---|---|
| Матрица смежности | Хранение графа |
| Список смежности | Компактное хранение рёбер |
| `set` | Хранение уникальных рёбер |
| DFS | Поиск в глубину |
| BFS | Поиск в ширину |
| `deque` | Реализация очереди |
| `list` | Реализация стека |
| `visited` | Учёт посещённых вершин |
| `color` | Раскраска вершин графа |
| `dist` | Хранение расстояний |
| `parent` | Восстановление пути |
| Топологическая сортировка | Упорядочивание вершин с учётом зависимостей |

## Основные оценки сложности

| Операция | Сложность |
|---|---|
| Проверка матрицы смежности | O(N²) |
| DFS с матрицей смежности | O(N²) |
| BFS с матрицей смежности | O(N²) |
| DFS со списком смежности | O(N + M) |
| BFS со списком смежности | O(N + M) |
| Поиск всех компонент связности | O(N + M) |
| Проверка двудольности | O(N + M) |
| Проверка топологического порядка | O(N + M) |

**Обозначения:**
- N — количество вершин графа.
- M — количество рёбер графа.
